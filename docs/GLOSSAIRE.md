# Glossaire

## Termes du mouvement

| Terme | Signification |
|---|---|
| Territoire de coordination | Pays, région ou commune dont un coordonnateur a la charge. Les territoires sont emboîtés. |
| Bureau exécutif | Ensemble des coordonnateurs, fondateurs compris. |
| Membre fondateur | Membre du bureau exécutif aux droits renforcés. Seul à examiner les demandes d'adhésion. |
| Coordonnateur | Représentant d'un territoire, membre du bureau exécutif. |
| Membre simple | Membre rattaché à un territoire, sans fonction au bureau. |
| Visiteur | Personne qui n'est pas encore membre. |
| Demande d'adhésion | Dossier déposé par un visiteur. Statuts : À examiner, Acceptée, Rejetée, Inscrite. |
| Lien personnel | Adresse unique envoyée par courriel, valable 7 jours et utilisable une seule fois. |
| Programme | Ensemble d'actions du mouvement sur un territoire, avec objectif, dates et état. |
| Activité | Action datée d'un programme, avec lieu, compte rendu et participants. |
| Carte numérique | Carte de membre affichée, téléchargeable et imprimable. |

## Termes du projet

| Terme | Signification |
|---|---|
| Cahier des charges | Document qui décrit ce que la plateforme doit faire ([PDF](Cahier-des-charges-TABAXI.pdf)). |
| Histoire d'utilisateur | Besoin écrit « En tant que… je veux… afin de… ». |
| Sprint | Période courte de travail (ici 2 jours ouvrés) avec des objectifs précis. Un sprint correspond à un milestone GitHub. |
| Epic | Grand bloc de travail qui regroupe plusieurs issues. |
| Backlog | Liste priorisée de tout le travail à faire. |
| Critères d'acceptation | Conditions qui prouvent qu'une tâche est terminée. |
| Recette | Phase où les fondateurs vérifient que la plateforme fait ce qui est demandé. |
| CDP | Commission de protection des données personnelles du Sénégal. |

## Termes techniques

| Terme | Signification |
|---|---|
| API | Interface par laquelle le frontend demande des données au backend. |
| Backend | Partie serveur (Django) : règles, droits, base de données. |
| Frontend | Partie visible dans le navigateur (Angular). |
| Migration | Fichier qui fait évoluer la structure de la base de données. |
| Session | Connexion mémorisée entre le navigateur et le serveur après identification. |
| Pull Request | Demande de fusion d'une branche dans `main`, avec relecture. |
