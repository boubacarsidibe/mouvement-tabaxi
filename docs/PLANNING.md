# Planning des sprints

Sprints de 2 jours ouvrés, du jeudi 15 au jeudi 29 octobre 2026 (rendu). Les hypothèses de calendrier sont détaillées dans [HYPOTHESES.md](HYPOTHESES.md). Les tâches sont suivies dans les [sprints GitHub](https://github.com/boubacarsidibe/mouvement-tabaxi/milestones).
